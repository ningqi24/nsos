# nsos UI 设计理念

## 核心原则

**功能优先，形式服从。** 每一个视觉元素都必须服务于明确的功能目的。不为装饰而装饰，不为"好看"而增加冗余。

**克制的现代化。** 借鉴 iOS 的精准与 Material Design 的层次，但不盲从。取其骨架，去其臃肿。

---

## 设计语言

### 1. 层次与深度

- **三层结构**：背景层（壁纸）、内容层（卡片/列表）、悬浮层（弹窗/状态栏）
- **深度表达**：通过模糊（backdrop-filter）、阴影、不透明度三者的组合表达层级，而非单纯的 z-index 堆叠
- **玻璃材质**：系统级浮层统一使用毛玻璃效果，透明度 70%-85%，模糊半径 20px-40px，带 1px 顶部高光描边

### 2. 圆角

- 控件圆角：12px（按钮、输入框、列表项）
- 卡片圆角：16px（面板、弹窗）
- 系统级浮层圆角：20px-24px（控制中心、通知、分享面板）
- 应用图标圆角：根据图标网格自适应，不强制统一

**原则**：半径与元素尺寸成正比。大元素大圆角，小元素小圆角。

### 3. 间距

采用 4px 基数的间距系统：

| 级别 | 像素值 | 用途 |
|------|--------|------|
| xs   | 4px    | 图标内边距、紧凑标签 |
| sm   | 8px    | 列表项内间距、小组件内边距 |
| md   | 12px   | 卡片内边距、表单控件间距 |
| lg   | 16px   | 页面内边距、模块间距 |
| xl   | 24px   | 大区块间距、弹窗内边距 |
| 2xl  | 32px   | 首屏大标题上下间距 |

### 4. 字体

- 系统字体栈：`-apple-system, BlinkMacSystemFont, 'SF Pro Display', 'PingFang SC', 'Segoe UI', Roboto, sans-serif`
- 等宽字体：`'SF Mono', 'JetBrains Mono', 'Fira Code', Consolas, monospace`
- 字重使用：常规 400，中等 500，粗体 600。避免 700 及以上，除非品牌标识
- 字号层级：
  - 大标题：28px / 34px 行高
  - 标题1：22px / 28px 行高
  - 标题2：17px / 22px 行高，字重 500
  - 正文：15px / 20px 行高
  - 次要文字：13px / 18px 行高
  - 辅助文字：11px / 14px 行高

### 主色

| 名称 | 暗色值 | 亮色值 | 用途 |
|------|--------|--------|------|
| 品牌蓝 | #0A84FF | #007AFF | 主按钮、链接、选中态、进度条 |
| 品牌绿 | #30D158 | #34C759 | 成功、开启状态、正向操作 |
| 品牌橙 | #FF9F0A | #FF9500 | 警告、待处理、可更新 |
| 品牌红 | #FF453A | #FF3B30 | 错误、删除、危险操作 |

### 中性色（暗色优先）

| 层级 | 暗色值 | 亮色值 | 用途 |
|------|--------|--------|------|
| 背景 | #000000 | #F2F2F7 | 最底层背景 |
| 表面1 | #1C1C1E | #FFFFFF | 卡片、列表背景 |
| 表面2 | #2C2C2E | #F2F2F7 | 分组背景、次级表面 |

| 文字次 | #98989D | #8E8E93 | 次要信息、说明文字 |

### 语义规则

- 颜色必须表达语义，不可随意选用
- 同一语义在全系统内使用同一色值，不允许同一含义多种表达
- 深色/浅色主题通过 CSS 变量切换，变量名使用语义命名而非颜色命名

## 组件规范

### 按钮

| 类型 | 样式 | 使用场景 |
|------|------|----------|
| 主按钮 | 实色填充，白字，12px 圆角 | 主要操作（确认、安装、登录） |
| 次按钮 | 透明背景，描边，文字与边框同色 | 次要操作（取消、返回） |
| 文字按钮 | 无背景无描边，仅文字 | 列表操作、链接式按钮 |
| 图标按钮 | 圆形/方形背景 + 图标 | 工具栏、快捷操作 |

- 按钮高度：44px（标准），36px（紧凑）
- 按下态：透明度 70% + 轻微缩放 0.97
- 禁用态：透明度 40%，cursor: not-allowed

### 列表

- 列表项高度：44px（标准），56px（带副标题）
- 左侧图标/头像：28px-32px，右间距 12px
- 右侧箭头/开关：距右边缘 16px
- 分隔线：左缩进 52px（与左侧图标后对齐），1px 实线
- 分组列表：每组顶部有组标题（13px，次要文字色，大写或正常），组间间距 24px

### 卡片

- 背景：表面1色值
- 圆角：16px
- 内边距：16px
- 阴影：暗色 0 2px 12px rgba(0,0,0,0.3)，亮色 0 2px 12px rgba(0,0,0,0.08)
- 卡片之间间距：12px

### 弹窗 / Sheet

- 居中弹窗：宽度 280px-340px，圆角 16px，背景半透明模糊遮罩
- 底部 Sheet：从底部滑入，顶部圆角 20px，顶部有小横条把手
- 出现动画：0.3s 缓出（cubic-bezier(.35,.7,.2,1)）
- 消失动画：0.25s 缓入

## 动效规范

### 基本原则

- **快而不仓促**：所有过渡动画控制在 200ms-400ms 之间
- **有加速度**：使用缓动曲线，避免线性运动。出使用 ease-out，入使用 ease-in
- **跟手优先**：可交互的拖拽操作必须实时跟随手指/指针，延迟低于 16ms
- **打断安全**：动画可被反向操作打断，状态保持连续

### 标准缓动曲线

- 出场（元素出现、进入）：cubic-bezier(.35,.7,.2,1)
- 入场（元素消失、退出）：cubic-bezier(.4,0,.2,1)
- 弹性回弹：cubic-bezier(.175,.885,.32,1.275) —— 仅用于小型强调元素

### 禁用场景

- 纯功能性操作（如开关切换、复选框勾选）可简化为 100ms 淡入淡出
- 低性能设备降级：减少模糊半径，关闭非必要动画

## 交互原则

### 1. 直接操作

用户应能直接操作界面元素，而非通过中间层代理。能拖拽的就不做按钮，能点击的就不藏在菜单里。

### 2. 状态可见

系统状态必须清晰可感知。加载中、成功、失败、空状态——每种状态都有明确的视觉反馈，不依赖文字说明。

### 3. 容错设计

- 不可逆操作必须二次确认（删除、重置、刷机）
- 可撤销操作提供撤销入口（如删除通知）
- 手势操作有回弹兜底——拉不到阈值就弹回去，无损失

### 4. 一致性

- 相同的功能在不同页面使用相同的交互模式
- 相同的视觉元素表达相同的含义
- 手势方向统一：上滑=展开/解锁，下滑=收起/通知，左滑=删除/更多

## 反模式清单

以下设计严格禁止：

1. **装饰性元素**：无功能意义的线条、图形、纹理
2. **渐变滥用**：超过三色的渐变、高饱和撞色渐变
3. **过度动画**：超过 500ms 的过渡、弹跳幅度过大的弹性动画
4. **拟物化**：木纹、皮革、金属质感等拟物风格
5. **文字冗余**："请点击按钮进行下一步操作"这类废话
6. **伪 3D**：翻转、翻页、立方体等炫技式 3D 转场
7. **多色系主题**：每个应用一个色调，造成视觉混乱
8. **装饰性图标**：为了"不空"而加的无意义图标

---

## 响应式

- 设计基准：390px x 844px（类手机尺寸）
- 最小宽度：320px
- 内容最大宽度：480px（超过则居中留白）
- 横竖屏：竖屏优先，横屏时内容居中显示，两侧留边

---

## 实现约定

- 所有颜色、圆角、间距、阴影使用 CSS 变量定义，禁止硬编码
- 组件样式优先复用通用类（`.btn`、`.card`、`.list-item`），不重复定义
- 暗色/亮色主题通过 `[data-theme="light"]` 属性切换变量值
- 动画使用 CSS transition / transform，避免 JS 动画
- 图标使用 SVG 内联或 CSS mask，方便变色
